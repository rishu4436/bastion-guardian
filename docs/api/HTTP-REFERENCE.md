# BASTION Guardian API — HTTP reference (v1.0.0)

_Generated by `pnpm --filter @bastion-guardian/api openapi` from the route schemas. Do not edit by hand._

Versioned (/v1) API. Sessions use Sign-In with Ethereum (EIP-4361): GET /v1/auth/nonce → sign → POST /v1/auth/verify. State-changing authenticated calls require the X-CSRF-Token header. Data on chain 31337 is LOCAL SIMULATION output.

Conventions: amounts, health factors (1e18 WAD) and block numbers are decimal integer strings. Errors are `{ error: CODE, message }`. State-changing calls with a session need `X-CSRF-Token` (mint with `POST /v1/auth/csrf`, JSON body). Rate limits: 120 requests/min per client by default (Redis-shared across instances), stricter on auth, channel and test-notification routes. Machine-readable spec: [`openapi.json`](./openapi.json); interactive docs at `/docs` on any API instance.
