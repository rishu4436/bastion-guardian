## B. Economic & security invariants (Section 21)

| Invariant                                               | Where enforced                        | Test                                                                                                                            |
| ------------------------------------------------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Cumulative repay/fees never exceed signed policy limits | `PolicyRegistry.consume`              | `invariant_totalSpendWithinAuthorization`, `testFuzz_consumeNeverExceedsCaps`                                                   |
| A rescue is reimbursed at most once                     | Escrow state machine, vault           | `invariant_noDoubleReimbursement`, `test_duplicateSettlementCallbackPaysOnce`, `test_hookTokenRecipientCannotReenterSettlement` |
| Vault always backs its obligations                      | `totalHeld` accounting                | `invariant_vaultFullyBacked`, `testFuzz_freeFundsAlwaysWithdrawable`                                                            |
| Executors never retain funds                            | balance-delta checks, surplus refunds | `invariant_executorsHoldNothing`                                                                                                |
| Replays never re-execute                                | router/core dedup + ledger            | `invariant_replaysAndRescuesSafe`                                                                                               |
| Solver inventory = available + committed                | `SolverLiquidityVault`                | `invariant_solverInventoryBacked`                                                                                               |
| Ledger pending count consistent                         | `RescueSettlementLedger`              | `invariant_pendingSettlementsConsistent`                                                                                        |
| Rescue improves HF and reduces debt or reverts          | executors' post-checks                | Flash/E2E tests, fork tests                                                                                                     |
| Repay amount minimal for target (within rounding)       | `HealthFactorMath` + adapter buffer   | `testFuzz_minimality`, TS randomised test                                                                                       |
| TS math/digests equal Solidity                          | —                                     | `CrossLanguageVectors.t.sol` ⇄ `math.test.ts`, `policy.test.ts`                                                                 |
